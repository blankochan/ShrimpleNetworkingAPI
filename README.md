# ShrimpleNetworingAPI

I dont really have much to put here, this exists as my attempt at a universal networking API for Airframe Ultra.

Currently the only features are:
* Hiding Modded Games from vanilla players without causing disruption (primary reason I made this)
* Work in progress API for filtering out incompatible games (currently just hides them but in the future id like it to grey out an incompatible lobby and let you see the reason why a lobby was greyed out)
* Simplistic One Time property sync
